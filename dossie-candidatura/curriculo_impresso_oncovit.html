Projetos Técnicos em Destaque
1. Oncovit Sankhya Med Sync — Microsserviço de Rastreabilidade & Integração ERP Java 17 • Spring Boot 3 • SQL • Docker • ZPL II • Swagger
Aplicação desenvolvida para resolver os desafios críticos da distribuição farmacêutica hospitalar:
  • Cadeia de Frio Sanitária: Segregação automatizada de medicamentos termolábeis (2°C a 8°C) e ambiente com regras RDC 430 ANVISA.

  • Geração ZPL II: Formatação instantânea de etiquetas térmicas com tarja de câmara fria e DataMatrix para expedição.
  • Ambiente Vivo: Deploy ativo em container Docker na nuvem com Swagger UI: http://46.62.144.28:8080/swagger-ui/index.html
